# Arquitectura de aplicaciones con .NET

Reconstrucción de práctica del curso **Arquitectura de Aplicaciones Empresariales con .NET 10**, de **Alex Espejo Chavarría** en Udemy. El código de partida proviene de los materiales del instructor; este repositorio no atribuye su autoría original al alumno ni afirma que el curso esté terminado.

## Límite de esta reconstrucción

Se conservará la base de **.NET 9** de los recursos `Pacagroup.Ecommerce_v01.zip` y `Pacagroup.Ecommerce_v02.zip`: estructura por capas, contratos de dominio e inyección de dependencias del dominio. El temario público sitúa esos temas antes de la clase 22 (implementación de Repository). No se incluye esa implementación ni etapas posteriores mientras no se verifique el alcance siguiente.

Una observación histórica situó la reproducción en la clase 22, pero no demuestra que esa clase estuviera completada. Este corte es conservador, no una certificación del progreso personal actual. Ver [trazabilidad](docs/trazabilidad.md).

## Estado

Preparación del historial por etapas. Los commits tienen la fecha real de la reconstrucción; no simulan actividad pasada.
